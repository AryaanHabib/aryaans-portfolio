Arena

Multiplayer game server. Solo project, August 2026.

A multiplayer game server where the server owns the truth, and any match can be replayed exactly from its inputs.

Film notes
  • One platform thread owns the world and runs a fixed 20 Hz tick. Inputs from the network go through queues and are validated at one boundary that drops bad input instead of throwing.
  • Deterministic on purpose: fixed-point integers for positions, a precomputed sine table, one seeded random generator, and a test that fails the build if anything nondeterministic enters the simulation code.
  • A binary WebSocket protocol sends each player only what changed since the last state they acknowledged, and login tokens are checked during the handshake.
  • The replay above is a line-for-line JavaScript port of the Java simulation. It reproduces every recorded hash bit for bit.

Built with Java 21, Spring Boot 3, WebSockets, Micrometer, JUnit 5 (159 test methods)

Not built yet Lag compensation. It is designed and written up in the README.

Film notes
  • The Go service is tiny and dependency-free, with a minimal Redis client. If queuing fails it deletes the dedupe key so GitHub's retry can get through.
  • Comments are placed by GitHub's diff position, which keeps counting across hunks and restarts per file. If GitHub rejects one anyway, the findings go into one summary review instead of being lost.
  • An evaluation harness runs 10 seeded-bug fixtures through the same pipeline to measure precision, recall, cost and latency. Results aren't published yet.

Built with Go, Python, FastAPI, Redis, PostgreSQL, OpenAI API, Next.js, Docker Compose

    Film notes
    • The silent race: two bids that read the same price both "succeeded", and the later write won even when it was lower. Supabase doesn't report an update that matches zero rows, so nothing flagged it.
    • The fix is compare-and-swap on bids, lot closes and phase changes, so a player can't be sold twice or charged twice.
    • Every client tries to advance the timers and a cron job backs them up, so the draft keeps going when the commissioner closes their tab. A $1 reserve per empty roster spot means every team can finish its roster.

    Face Value

    NBA shot-quality model. Solo project, June 2026.

    Twenty-five points on open looks and twenty-five on contested ones look the same in a box score. This model grades scorers on how hard their shots were.

    Shots modeledPlayers gradedSynthetic check
    219K350r = 0.96

    350 players, 2025-26 season

    +0.0

    O madeX missed
      Film notes
      • A gradient-boosted model gives every one of about 219,000 shots a make probability from its location, distance and type, which becomes expected points.
      • Players are graded on actual minus expected points per 100 shots, with a correction for how closely they were guarded.
      • Before trusting it, I tested it on made-up players with a hidden skill level. It recovered that skill with a 0.96 correlation.

      Built with Python, scikit-learn, pandas, Next.js, Vercel
